# TakenokoShader

Unity 2022.3 向けのシェーダーパッケージです。VRChat Worlds SDK / UdonSharp に依存せず利用できます。

エリアライトの UdonSharp コンポーネント、Prefab、LUT、ライト用マテリアルは
`com.kinankomoti.takenokoshaderarealight` に分離されています。
エリアライトを利用するワールドには追加でインストールしてください。

ShaderBindingExporter は開発用の独立パッケージ
`com.kinankomoti.shaderbindingexporter` です。本パッケージの利用に必要ありません。

配布手順は [VPM 配布ガイド](../../VPM~/README.md) を参照してください。
