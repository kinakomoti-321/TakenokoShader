# Install

[VPM Repository](https://kinakomoti-321.github.io/vpm-listing/) からインストールできます。

また、手動でインストールする場合は [GitHub](https://github.com/kinakomoti-321/TakenokoShader/releases/) から unitypackage をダウンロードしてください。

- TakenokoShader : Shader 本体のパッケージ

- TakenokoShaderAreaLight : Area light 機能のパッケージ。Area light を使用する場合はインストールしてください。
