# Area Light

Area light を使用するには、**専用のパッケージをインストールする必要があります**。専用のパッケージは [Install](./install) の手順に従ってインストールしてください。

Area light とは面積を持つ光源のことです。通常の punctual light (点光源など) とは異なり、スクリーンのような大きな面積を持つ光源を表現することができます。

Takenoko shader では計 8 個までの quad 形状の area light を扱うことができます。
